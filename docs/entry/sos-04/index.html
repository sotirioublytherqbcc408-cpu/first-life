第一次被诈骗：电话、短信与转账之后怎么办

证据 B花费：可能损失全部余额耗时：越快越好力气：高最后核对：2026-10-05

怎么办

被骗转账后的黄金时间是前几十分钟：先打银行客服要求止付/冻结，再打 110 报警，同时把诈骗短信、号码举报到 12321。

  1. 立刻打银行客服（卡背面号码）要求止付、冻结账户、查询资金去向
  2. 打 110 报警，带上转账记录、对方账号、聊天截图
  3. 把诈骗短信/骚扰电话举报到 12321，网络诈骗信息举报到 12377
  4. 把对方账号提交给银行与警方，越早越可能拦截

容易踩什么坑

  • 不要相信「网上追款」「黑客帮你要回钱」，那是二次诈骗
  • 不要因为羞愧而拖延，止付窗口很短

依据

  • 12321 网络不良与垃圾信息举报受理中心
    受理垃圾短信、诈骗电话与不良信息的举报
  • 中国政府网（政策与办事服务入口）
    转账被骗后应第一时间联系银行止付并向公安机关报案

它覆盖了哪些「第一次」

  • 第一次被诈骗
  • 第一次收到诈骗电话
  • 第一次收到钓鱼短信
  • 第一次被骗转账
  • 第一次联系银行止付
