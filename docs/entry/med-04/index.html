第一次做心电图、B 超、X 光、CT 和核磁

证据 A花费：几十元到上千元不等耗时：每项 10–40 分钟，CT/核磁可能预约力气：中最后核对：2026-10-05

怎么办

心电图、B 超、X 光、CT、核磁是五类不同的检查，开哪一项由医生根据病情决定。X 光和 CT 有电离辐射，属于放射诊疗，机构必须有相应许可；核磁没有电离辐射，但体内有金属植入物、心脏起搏器的人不能随便做，必须提前告知医生。

  1. 缴费后到相应科室（放射科/超声科/心电图室）预约或取号，CT、核磁常常要排到几天后。
  2. 检查前如实告诉医生：是否怀孕或可能怀孕、体内有没有金属/植入物、有没有造影剂过敏史。
  3. 做检查时按要求去除金属物品、按要求屏气或保持不动，动了就要重做。
  4. 取报告时连同影像胶片/电子影像一起保存，复诊和转院都要用。

容易踩什么坑

  • 把核磁当成“更高级的 CT”主动要求做，检查项目应由医生判断。
  • 隐瞒怀孕或金属植入物，可能造成风险和检查失败。
  • 只拿文字报告不拿影像，换医院时可能要重做。

依据

  • 放射诊疗管理规定（中国政府网）
    页面含“放射诊疗”（84 处）、“射线”，规定放射诊疗许可、防护与受检者告知要求。
  • 医疗机构管理条例（安徽省卫生健康委员会）
    页面含“医疗机构”“诊疗”，用于核对开展检查项目需具备的执业条件。
