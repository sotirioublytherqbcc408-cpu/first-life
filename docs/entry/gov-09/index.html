第一次办住房公积金

证据 A花费：单位和个人按比例共同缴存耗时：开户由单位办，提取线上几分钟力气：低最后核对：2026-10-05

怎么办

住房公积金是单位和职工共同缴存的长期住房储金，可用于购房、租房、还贷等提取，也能申请公积金贷款。缴存和提取的规则由条例和地方细则共同规定，各地额度与条件差别不小。

  1. 入职后确认单位为你在当地公积金中心开户并缴存，用公积金 App 或小程序查询余额和缴存明细。
  2. 需要提取时，先看自己符合哪种情形（购房、租房、还贷、退休等），按当地要求准备材料线上申请。
  3. 想用公积金贷款，先查当地最高额度、缴存月数要求和首付比例。
  4. 换城市工作时办理异地转移接续，缴费年限通常可以累计。

容易踩什么坑

  • 找人“代提公积金”多数是骗提，被发现要退回并影响信用。
  • 以为缴存比例越高越好，实际到手工资会同步变少，需自己权衡。
  • 离职后不办转移，账户长期封存，买房时才发现年限断档。

依据

  • 住房公积金管理条例（国务院令第 844 号修订，国务院公报）
    页面含“住房公积金”（241 处）、“提取”（32 处）、“缴存”（56 处），规定缴存、提取与贷款的基本规则。
