第一次买机票：选航班、看懂机场代码与退改签规则

证据 B花费：因人而异耗时：30—60 分钟力气：低最后核对：2026-10-05

怎么办

买机票不是挑最便宜的就行。票价、退改签规则、行李额是三件独立的事，同一航线不同价格的票，能退能改的程度差很远。机票上写的是机场三字码，一座城市有两个机场时，光看城市名容易买错。

  1. 先定日期时段，再看直飞还是中转；中转要留够衔接时间。
  2. 在航司官网或正规 OTA 比价，重点看退改签规则、免费行李额、是否代码共享。
  3. 核对机场三字码和航站楼，乘机人信息用你出行会带的证件。

容易踩什么坑

  • 最便宜的票通常退改最严，买前一定点开规则看清楚。
  • 别找“先占座后倒卖”的代理，出问题找不到人。

依据

  • 民航局航旅指南·客票销售
    乘机有效证件种类；购票证件须与值机、安检证件一致；折扣越大退改限制越严；行程单是报销凭证且一般只能打印一次。
  • 《公共航空运输旅客服务管理规定》（交通运输部令2021年第3号）
    第八条要求运输总条件包含客票销售和退票、变更实施细则与超售处置规定；第十五条要求售票时告知退改规则；第三十七条明确免费行李额、超限行李费、行李损坏丢失赔偿标准须在运输总条件中列明。
