第一次面对竞业限制和保密协议

证据 A增补花费：可能影响下一份工作耗时：30 分钟力气：中最后核对：2026-10-05

怎么办

入职时一并签的竞业限制协议，会影响你离职后能不能去同行。看清三件事：限制范围、期限、有没有补偿。

  1. 确认自己是否属于「负有保密义务的人员」，普通岗位一般不受竞业限制约束
  2. 看限制期限（最长不超过二年）、地域与业务范围
  3. 竞业限制必须约定并支付经济补偿，没补偿的可主张不受约束
  4. 离职时书面确认是否启动竞业限制

容易踩什么坑

  • 签了没补偿的竞业协议就自我限制，白白错过机会
  • 把保密义务和竞业限制混为一谈

依据

  • 《中华人民共和国劳动合同法》（国务院公报版）
    竞业限制的人员范围、期限（不超过二年）与经济补偿要求

为什么补这一条

入职一并签的协议会影响下一份工作，离职前必须知道范围与补偿
