第一次搞懂行程单：报销凭证只能打印一次

证据 B增补花费：0耗时：10 分钟力气：低最后核对：2026-10-05

怎么办

行程单是机票的付款与报销凭证，一般只能打印一次；退票改签时往往要交回原件，所以拿到先拍照留底。

  1. 在航司柜台、官网或自助机打印行程单，注意打印期限
  2. 打印后先拍照存档，再交给财务
  3. 退改签前问清是否需要交回原件
  4. 电子发票逐步推广，出差前先问公司财务认哪种凭证

容易踩什么坑

  • 以为能随时补打，过期或已打印就开不出来
  • 把唯一原件直接交出去，之后无法核对金额与税费

依据

  • 民航局航旅指南
    航旅指南中关于行程单用途与打印次数的说明
  • 《公共航空运输旅客服务管理规定》（交通运输部令 2021 年第 3 号）
    承运人应公示客票与退改规则

为什么补这一条

行程单是报销凭证且一般只能打印一次，是典型新手坑
