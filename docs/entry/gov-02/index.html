第一次办护照、港澳通行证，第一次去出入境大厅和办签证

证据 A花费：护照/通行证工本费按国家规定，签证费按目的地国耗时：办证约 7–15 个工作日（以受理回执为准）力气：中最后核对：2026-10-05

怎么办

护照和往来港澳通行证由公安机关出入境管理机构签发，签证则由目的地国家的驻华使领馆或签证中心签发——顺序是先有护照，再谈签证。办证现在基本都要先线上预约，再去出入境大厅现场办理。

  1. 在国家移民管理局 App 或当地政务平台预约，选办理地点和时间。
  2. 按预约到出入境大厅：带身份证、现场拍照、采集指纹、填写申请表、缴费，选择邮寄或自取。
  3. 拿到护照后，按目的地要求准备签证材料（行程、住宿、在职或在读证明、资金证明等），通过使领馆官网或授权签证中心递交。
  4. 港澳出行还要选对签注类型（个人旅游、团队旅游、探亲等），签注有效期和次数按出行计划选。

容易踩什么坑

  • 护照有效期不足（很多国家要求剩余 6 个月以上）会影响签证和入境，出行前先看有效期。
  • 首次办护照必须本人到场，找人代办是违规的。
  • 轻信“包过签证”的中介，材料造假会被拒签并留下记录。

依据

  • 中华人民共和国护照法（国务院公报）
    页面含“护照”（92 处）、“普通护照”（12 处），规定护照的申请、签发与有效期。
  • 普通护照签发服务指南（商务部国家层面海外综合服务平台转载）
    页面含“护照”（82 处）、“申请”（86 处）、“出入境”（36 处），列明申请材料与办理流程。
  • 往来港澳通行证和签注签发服务指南（商务部国家层面海外综合服务平台转载）
    页面含“港澳”（107 处）、“签注”（123 处），列明通行证与各类签注的申请材料。
  • 中国领事服务网（外交部）出国签证栏目
    页面含“签证”（32 处），是外交部发布各国签证信息与提醒的官方栏目。
