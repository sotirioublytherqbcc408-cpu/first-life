第一次请假与旷课

证据 A花费：免费耗时：10 分钟力气：低最后核对：2026-10-05

怎么办

请假要走学校规定的流程，一般是辅导员审批或在教务系统提交；没批就不去上课算旷课，累计到一定学时可能影响考试资格甚至被处分。

  1. 先查学生手册或教务系统里的请假规定，看清谁能批、几天内有效。
  2. 提前提交申请，写清时间、事由，病假附上病历或诊断证明。
  3. 把请假结果同步给任课老师，别只走系统。
  4. 回校后按学校要求办销假手续。
  5. 缺的课自己补上，笔记找同学借。

容易踩什么坑

  • 先不上课再补请假，很多学校不认。
  • 旷课累计到学校规定的学时会被取消考试资格，具体标准写在学生管理规定和学校细则里。
  • 找人代课、代签到属于违纪，代价远大于一节课。

依据

  • 《普通高等学校学生管理规定》（教育部令第41号）
    含入学与注册（未请假或请假逾期视为放弃入学资格）、考核与成绩记载（考核不合格课程是否重修或补考由学校规定；作弊成绩记无效并可给处分）、转专业、休学、退学、住宿管理、学业证书管理、申诉等章节
  • 《普通高等学校学生管理规定》（教育部官网版本）
    教育部官网现行文本，含学籍、转专业、考核等条款，便于逐条核对
