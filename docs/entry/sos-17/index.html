第一次学心肺复苏（CPR）与 AED

证据 B花费：培训常免费耗时：半天力气：中最后核对：2026-10-05

怎么办

CPR 与 AED 是救回心脏骤停的唯一有效手段，值得专门去上一次线下课。核心动作是：判断无反应无呼吸 → 呼救取 AED → 胸外按压 30:2。

  1. 判断：拍肩呼喊无反应、无正常呼吸 → 立即呼救并让人取 AED
  2. 按压：两乳头连线中点，深度 5–6 厘米，频率 100–120 次/分
  3. AED 到手就开机，按语音提示贴片、放电，不要碰触患者
  4. 持续到患者恢复或急救人员接手

容易踩什么坑

  • 不敢按、按得太浅是最常见问题，宁可用力
  • AED 有语音提示，非专业人员也能用

依据

  • 中国红十字会总会（救护培训与急救知识）
