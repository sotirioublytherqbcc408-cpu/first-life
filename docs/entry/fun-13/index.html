第一次参加朋友聚餐、第一次请客、第一次买单、第一次 AA

证据 C花费：人均几十到几百元耗时：2 小时力气：低最后核对：2026-10-05

怎么办

买单这件事没有标准答案，但有标准做法：谁发起、谁先说，说清楚就不会尴尬。

  1. 聚餐前说清是 AA 还是有人请客，别等结账时再推让。
  2. AA 用转账或群收款，按人头平摊最简单；有人没喝酒就少算一份酒水钱，大家心里都舒服。
  3. 请客的人提前去结账，不要在桌上把账单传来传去。
  4. 点菜按人数配：几人点几道，再加一个汤，吃不完打包。

容易踩什么坑

  • 说好 AA 却有人一直往后躲，最后没人愿意再组局。
  • 点菜时谁都不点、最后点一堆没人吃的菜。

依据

  • 中华人民共和国反食品浪费法（中国人大网）
    规定餐饮服务经营者应引导消费者按需适量点餐、提供打包服务，消费者应合理点餐。 已用 curl 抓取本页并核对到关键词：「反食品浪费」、「按需」、「打包」。
  • 《中华人民共和国民法典》全文（贵阳市人大网站转载新华社受权发布全文）
    第五百八十六条规定定金合同自实际交付定金时成立，定金数额不得超过主合同标的额的百分之二十；第一千零四十五条界定近亲属范围；第一千零四十三条倡导家庭成员敬老爱幼、互相帮助。 已用 curl 抓取本页并核对到关键词：「定金」、「近亲属」、「敬老爱幼」、「家风」。
