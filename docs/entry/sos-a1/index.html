第一次给家人做一张「应急信息卡」

证据 C增补花费：0耗时：30 分钟力气：低最后核对：2026-10-05

怎么办

一张卡片写清：过敏史、常用药、主治医院与医生、紧急联系人、保险单号。钱包里放一份，手机锁屏里存一份。

  1. 列出每个家庭成员的过敏史、慢性病、常用药
  2. 写上主治医院、科室与医生电话
  3. 填两个紧急联系人与保险单号
  4. 打印两份：一份放钱包，一份贴冰箱

容易踩什么坑

  • 信息过期比没有更危险，每半年核对一次
  • 不要写身份证号、银行卡号

依据

  • 中国红十字会总会（救护培训与急救知识）
    家庭应急准备与急救信息登记

为什么补这一条

出事时急救人员最需要这些信息，而家人往往说不清
