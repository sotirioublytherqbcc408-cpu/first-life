第一次坐城际、市域铁路

证据 B增补花费：按里程耗时：按线路力气：低最后核对：2026-10-05

怎么办

城际与市域铁路介于地铁和火车之间：有的能刷交通卡、有的必须实名购票，进站与安检规则也各不相同。

  1. 出行前查清这条线是「铁路」还是「地铁」制式，用哪个 APP 购票
  2. 支持刷卡/刷码的线路，出站也要刷一次
  3. 预留安检与换乘时间，别按地铁的节奏算

容易踩什么坑

  • 以为能随到随走，结果需要实名购票
  • 不同线路的票与交通码互不通用

依据

  • 交通运输部官网（城市客运与网约车管理）
    城际铁路与市域（郊）铁路的运营与票务以运营方公告为准

为什么补这一条

这类线路越开越多，规则又不统一，第一次坐最容易懵
