第一次看懂餐厅的附加费：茶位费、服务费、开瓶费

证据 A增补花费：人均十几到几十元耗时：5 分钟力气：低最后核对：2026-10-05

怎么办

结账时才发现被加收费用，是餐饮消费最常见的纠纷。关键是：收费项目必须事先明示，没提前告知的可以拒付。

  1. 入座先看菜单、桌牌、点餐小程序上的收费说明
  2. 对未提前告知的茶位费、服务费、开瓶费当场提出异议
  3. 要求提供消费明细，核对菜品单价与数量
  4. 协商不成保留小票与菜单照片，向市场监管部门投诉

容易踩什么坑

  • 只口头问一句「有没有服务费」，结账时才发现另收
  • 拍不到菜单价格证明，事后举证困难

依据

  • 《中华人民共和国消费者权益保护法》
    消费者有权知悉服务真实情况，经营者应按约定提供服务
  • 国家市场监督管理总局（明码标价与预付式消费监管）
    经营者应明码标价，不得收取未予标明的费用
