第一次收到工资：工资条、个税与到手多少

证据 A花费：到手 = 约定工资 - 个人社保公积金 - 个税耗时：每月一次力气：低最后核对：2026-10-05

怎么办

谈好的月薪和到手的钱不是一回事，中间要扣个人承担的五险一金和个人所得税。兼职、劳务报酬的预扣方式和正式工资不同，但年度汇算时会并入综合所得重新算一遍，多退少补。

  1. 拿到工资条，核对基本工资、绩效、扣款项目和实发金额。
  2. 看社保、公积金的个人缴纳部分是否和当地标准对得上。
  3. 看个税代扣金额，年度终了在个人所得税 App 里做汇算。
  4. 把工资到账记录保存好，办贷款、签证时要用。
  5. 兼职收入同样申报，避免汇算时补税措手不及。

容易踩什么坑

  • 「月薪八千」可能是税前，到手要少一截，入职前问清是税前还是税后。
  • 有的单位把工资拆成基本工资加补贴，社保基数按最低标准缴，直接影响你以后的待遇。
  • 试用期工资不得低于本单位相同岗位最低档工资或约定工资的八成，也不得低于当地最低工资标准，低于这个数可以问人事。

依据

  • 《工资支付暂行规定》
    规定工资应以法定货币支付、不得克扣或无故拖欠；解除或终止劳动合同时应一次付清劳动者工资
  • 《个人所得税综合所得汇算清缴管理办法》（国家税务总局令第57号）
    规定综合所得年度汇算的办理期限、办理方式（个人所得税App、网页端）与退补税流程
