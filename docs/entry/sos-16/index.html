第一次帮助受伤的人：该不该停

证据 C花费：0耗时：10–30 分钟力气：中最后核对：2026-10-05

怎么办

该停，但要按顺序做：先确保自己安全（车流、火源、电），再打 120/110，然后在不造成二次伤害的前提下帮忙。

  1. 判断现场是否安全，先保护自己（开双闪、站到护栏外）
  2. 打 120 说清地点与伤情，按接线员指导操作
  3. 不要随意搬动伤者；出血就加压止血
  4. 留在现场直到救援到场，并向急救人员说明情况

容易踩什么坑

  • 好心搬动颈椎/脊柱受伤者可能造成瘫痪
  • 不要给伤者喂水喂药

依据

  • 中国红十字会总会（救护培训与急救知识）
