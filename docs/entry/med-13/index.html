第一次骨折和第一次受伤

证据 A花费：几百元到数万元（视是否手术）耗时：数周到数月力气：高最后核对：2026-10-05

怎么办

外伤后的流程是：先判断有没有危及生命的情况，再去急诊→拍片→医生判断是固定还是手术。骨科的片子（X 光/CT）和病历要一路留好，复诊、换医院、走保险都用得上。

  1. 怀疑骨折时不要反复搬动受伤部位，用硬物临时固定后尽快去急诊。
  2. 到急诊挂骨科或创伤外科，配合拍片、必要时做 CT。
  3. 医生给出治疗方案（保守固定或手术）时，问清愈合时间、复查频率和注意事项。
  4. 把所有影像资料、诊断证明、发票留档；需要请假或报销时都要用。

容易踩什么坑

  • 觉得“能动能走”就不是骨折，拖几天才去医院，错过复位时机。
  • 自行找推拿、正骨处理明显变形或剧痛的部位。
  • 不按时复查，内固定或石膏出问题时才发现。

依据

  • 医疗机构管理条例（安徽省卫生健康委员会）
    页面含“医疗机构”“诊疗”，用于核对急诊、外科诊疗的执业要求。
  • 放射诊疗管理规定（中国政府网）
    页面含“放射诊疗”“射线”，规定 X 光、CT 等放射检查的许可与防护要求。
