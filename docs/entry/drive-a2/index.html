第一次给车做年检（上线检验）

证据 A增补花费：几百元耗时：半天力气：中最后核对：2026-10-05

怎么办

非营运小微型客车的检验周期分线上申领与上线检验两种：部分年份只需申领电子检验标志，部分年份要上检测线。

  1. 先确认自己车辆的检验周期（以行驶证签注和交管 12123 提示为准）
  2. 需要上线检验的，提前处理完违章、检查灯光刹车，再预约检测站
  3. 免检年份在 App 上申领电子检验标志，不用贴纸
  4. 检验有效期届满前办理，逾期上路会被处罚

容易踩什么坑

  • 逾期未检验仍上路，出事故时保险可能拒赔
  • 把「免检」理解成「什么都不用办」，忘记申领标志

依据

  • 《机动车登记规定》（公安部令第 164 号）
    机动车检验与登记的相关规定
  • 交管 12123 全国互联网交通安全综合服务管理平台
    检验标志电子化与预约渠道

为什么补这一条

第几年上线、第几年只申领标志，很多人记不清
