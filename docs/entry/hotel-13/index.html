第一次在酒店遇到停电和火警

证据 A花费：免费耗时：视情况力气：中最后核对：2026-10-05

怎么办

酒店停电和火警是两件事：停电通常等一会儿就恢复；火警响起时，无论真假都要按疏散通道走，不坐电梯、不留在房间观望。

  1. 停电先打前台确认是整栋还是单个房间，问预计恢复时间，不要自己开配电箱。
  2. 房间备一个小手电或用手电筒功能，停电时先找到门和房卡。
  3. 火警响起：穿鞋、拿房卡和手机，沿疏散指示从楼梯下楼，不乘电梯、不回去取行李。
  4. 到安全区域后听酒店和消防人员安排，需要时拨打119。

容易踩什么坑

  • 不要躲进房间等救援，疏散通道能走就走。
  • 公共场所应保障疏散通道和安全出口畅通，发现被堵立即向酒店反映。

依据

  • 《中华人民共和国消防法》
    任何单位、个人发现火灾都应当立即报警；公共场所应当保障疏散通道、安全出口畅通，并设置消防安全标志。
  • 上海市文化和旅游局：《旅游饭店星级的划分与评定》（GB/T14308—2010）
    标准修订说明：强化安全管理，将突发事件应急预案列为各星级必备条件；评定星级后发生重大安全责任事故将被取消星级。
