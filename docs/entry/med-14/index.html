第一次严重发烧和第一次突发疼痛

证据 A花费：急诊费用耗时：数小时力气：高最后核对：2026-10-05

怎么办

发烧和疼痛是症状不是诊断，该不该去急诊看的是“危险信号”：持续高热、意识不清、剧烈且突然的疼痛、伴随呕吐或呼吸困难等，出现这些要马上去医院。判断这部分请交给医生，本条只说流程。

  1. 先记录：什么时候开始、体温多少、疼在哪里、有没有其他症状、吃了什么药。
  2. 情况紧急或夜间加重，直接去急诊，到分诊台如实说明，配合分级评估。
  3. 带上身份证、医保凭证、近期化验单和正在服用的药。
  4. 离开医院前问清：什么情况下必须立刻再来、什么时候复诊、用药怎么用。

容易踩什么坑

  • 自己加大药量或混吃多种退烧、止痛药。
  • 白天拖着不去、晚上才挂急诊，检查科室夜里不一定全开。
  • 因为不想麻烦别人，一个人硬扛着去，路上出事没人知道。

依据

  • 医疗机构管理条例（安徽省卫生健康委员会）
    页面含“诊疗”“执业”“医疗机构”，规定医疗机构救治与转诊的基本要求。
  • 院前医疗急救管理办法（国务院公报）
    页面含“急救”“院前”，说明院前急救与院内急诊的衔接与呼叫响应。

它覆盖了哪些「第一次」

  • 第一次严重发烧
  • 第一次遇到突发疼痛
