第一次遇到交通事故（自己或别人）

证据 B花费：视责任耗时：1–数小时力气：中最后核对：2026-10-05

怎么办

先保人再保车：有人受伤先打 120，再打 122/110 报警，最后才谈保险。别私了到连证据都没留。

  1. 开双闪、摆三角牌，人员撤到护栏外
  2. 有人受伤打 120，同时打 122 报警
  3. 拍照取证：全景、接触点、刹车痕、车牌、路况
  4. 联系保险公司报案，留好事故认定书

容易踩什么坑

  • 高速上不要在车道内理论，二次事故更致命
  • 伤者不要随意搬动（除非有起火等危险）

依据

  • 交通运输部（道路运输与交通事故处理规定）
    道路交通事故处理程序与道路运输安全规定
