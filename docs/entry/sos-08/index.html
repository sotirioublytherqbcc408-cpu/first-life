第一次遇到火灾：初期处置、用灭火器、逃生

证据 A花费：0耗时：几分钟力气：中最后核对：2026-10-05

怎么办

记住顺序：先报警（119）、再决定灭还是跑。能灭就用灭火器对准火焰根部；灭不了立刻关门撤离，不要乘电梯、不要回房间拿东西。

  1. 喊人 + 打 119，说明楼层与起火物
  2. 灭火器：拔销、握管、压把，站在上风方向对准火焰根部左右扫射
  3. 逃生：低姿、湿毛巾捂口鼻、摸门把手（烫就不要开）、走安全通道
  4. 到安全地点后清点人数，告诉消防员是否还有人被困

容易踩什么坑

  • 楼道烟火比火本身更致命，别冲进浓烟
  • 高层不要跳楼，退到有窗房间封门缝等待救援

依据

  • 《中华人民共和国消防法》（2021 修正全文，北京市人民政府门户网站转载）
    各单位与个人有维护消防安全、保护消防设施、报告火警的义务；任何人发现火灾都应当立即报警（已 curl 核验页面含「消防法」「火灾」65 处、「灭火」15 处、「疏散」12 处）
  • 中国红十字会总会（救护培训与火场自救互救）
    救护培训课程含火灾现场的自救互救内容
