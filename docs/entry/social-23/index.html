第一次结束一段友谊、第一次学会保持边界

证据 B花费：无耗时：数周到数年力气：高最后核对：2026-10-05

怎么办

不是所有关系都要维系到底。疏远可以是渐进的：减少见面、不再倾诉、保留礼貌。这不算背叛，是成年人的常态。

  1. 先想清楚要结束的是什么：是整天黏在一起的模式，还是这段关系本身
  2. 优先做减法而不是宣告：减少见面频率，不主动分享私事
  3. 对方追问时直接说：「我最近想自己待着」，不必列举对方的错
  4. 涉及金钱、工作、共同朋友圈的，提前把自己的那份理清
  5. 把精力移回自己的生活，新的关系会自然长出来

容易踩什么坑

  • 在共同群里公开指责对方，会波及所有人
  • 一刀两断式的决裂常带来反复和拉扯，渐进更省力
  • 不必为「先退出的人」负罪，维护边界不是伤害别人
