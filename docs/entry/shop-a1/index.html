第一次用全国 12315 平台在线投诉

证据 A增补花费：0耗时：30 分钟力气：中最后核对：2026-10-05

怎么办

平台内投诉解决不了时，走全国 12315 平台（网站/App/小程序）。投诉要写清商家完整名称与统一社会信用代码，很多人到这一步才发现信息不全。

  1. 先向商家和平台投诉，保存工单号与聊天记录
  2. 在 12315 平台提交投诉：商家名称、信用代码、事实、诉求、证据
  3. 按平台时限补充材料，保持电话畅通
  4. 对处理结果不满意，可申请调解或向法院起诉

容易踩什么坑

  • 拿不出商家完整名称和地址，投诉会被退回补正
  • 把「退款」写成「赔偿」，诉求不明确也会影响处理

依据

  • 《市场监督管理投诉举报处理办法》（市场监管总局令第 121 号）
    投诉举报的受理范围、材料要求与处理时限

为什么补这一条

平台内投诉解决不了时的官方渠道，很多人卡在不知道商家全称
