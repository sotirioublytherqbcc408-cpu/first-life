第一次遇到地震

证据 B花费：0耗时：数十秒力气：中最后核对：2026-10-05

怎么办

地震来了先躲后撤：室内「伏地、遮挡、手抓牢」，躲桌子下护住头颈；震动停止后再走楼梯撤离，不要跳楼、不要坐电梯。

  1. 震动时：伏地 → 躲到坚固桌下或内墙墙角 → 护住头颈
  2. 远离窗户、吊灯、高柜
  3. 震动停止后走安全通道下楼，到空旷地
  4. 准备应急包：水、手电、口哨、常用药、证件复印件

容易踩什么坑

  • 地震时不要跑向阳台或电梯
  • 户外远离建筑外墙、电线杆与广告牌

  • 中国地震局
