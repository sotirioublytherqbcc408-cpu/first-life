第一次测血压、抽血和验尿

证据 A花费：血常规/尿常规几十元耗时：30–90 分钟力气：低最后核对：2026-10-05

怎么办

这三项是最基础的检查：血压当场出结果，抽血和验尿要去检验科，结果通常当天或次日取。抽血前是否需要空腹，按医生和检验科的要求来，别自己猜。

  1. 医生开单后先去缴费（自助机或手机都能交），再拿缴费单去检验科取号排队。
  2. 抽血前确认是否要求空腹；需要空腹的项目，前一天晚饭后就别吃东西，具体以检验科告知为准。
  3. 验尿一般取中段尿，容器上写清姓名和编号，避免污染样本。
  4. 按回执上的时间取报告，很多医院可以在公众号或 App 上直接看电子报告。

容易踩什么坑

  • 没空腹就去抽血，结果不准要重抽一次。
  • 抽血后按压时间不够，针眼淤青一片。
  • 报告随手丢，复诊时医生看不到趋势，只能重做。

依据

  • 医疗机构管理条例（安徽省卫生健康委员会）
    页面含“诊疗”“执业”等，用于核对医疗机构开展检验检查的基本要求。
  • 卫生部《健康体检管理暂行规定》（北京市人民政府网站）
    页面含“健康体检”（71 处），规定体检项目、体检报告与体检机构的管理要求。
