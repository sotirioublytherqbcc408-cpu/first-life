第一次报到：从录取通知书到宿舍

证据 A花费：学费住宿费按学校标准，另有被褥等杂费耗时：半天到一天力气：中最后核对：2026-10-05

怎么办

报到就是按录取通知书上的时间和地点，把身份核验、缴费、领材料、分宿舍几件事按顺序办完。流程看着杂，其实是固定的，跟着指示牌和志愿者走就行。

  1. 按录取通知书上的时间来校，带齐身份证、录取通知书、照片和缴费凭证。
  2. 到学院报到点核验身份，领学生证和校园卡，办缴费或助学贷款手续。
  3. 按分配结果去宿舍楼领钥匙，登记住宿信息。
  4. 需要迁户口的按学校要求交材料，不迁的不用管。
  5. 把辅导员电话和班级群存好，这是后面所有事的入口。

容易踩什么坑

  • 因故不能按期入学要向学校请假；未请假或者请假逾期，除不可抗力等正当事由外，会被视为放弃入学资格。
  • 报到期间是电信诈骗高发期，凡是让你转账的「老师」「学长」都先当面核实。
  • 别把身份证等证件原件交给别人代办，交复印件时写上用途。

依据

  • 《普通高等学校学生管理规定》（教育部令第41号）
    含入学与注册（未请假或请假逾期视为放弃入学资格）、考核与成绩记载（考核不合格课程是否重修或补考由学校规定；作弊成绩记无效并可给处分）、转专业、休学、退学、住宿管理、学业证书管理、申诉等章节
  • 中国高等教育学生信息网（学信网）
    学籍学历查询与在线验证报告的官方入口

它覆盖了哪些「第一次」

  • 第一次上大学
  • 第一次报到
