第一次联系中国使领馆、第一次在国外生病

证据 A花费：医疗费自理耗时：因人而异力气：高最后核对：2026-10-05

怎么办

在国外遇到麻烦，使领馆能帮的和你以为的不太一样：他们能指路、补证件、联系家人，但不替你付医药费。

  1. 记住两个号码：12308（外交部全球领事保护与服务应急热线）和当地的报警急救电话。
  2. 护照、钱包被偷，先报警拿报警证明，再联系使领馆补办旅行证件。
  3. 生病先去当地医院或诊所，保留全部单据，回国后按保险条款申请理赔。
  4. 出国前把行程、保单号、紧急联系人留给家人，并记住中国驻当地使领馆电话。

容易踩什么坑

  • 以为使领馆会垫付医疗费或出面解决纠纷，实际上主要是协助，费用仍由本人承担。
  • 没买旅行保险，境外医疗费用会高得吓人。

依据

  • 《中国领事保护与协助指南》和《中华人民共和国领事保护与协助条例》（中国驻外使馆网站）
