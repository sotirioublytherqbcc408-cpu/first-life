第一次在闲鱼买卖二手

证据 C花费：商品价格 + 运费耗时：30 分钟到几天力气：中最后核对：2026-10-05

怎么办

二手平台的核心是「描述一致」和「留痕」。买东西看实物图和细节图，卖东西把瑕疵拍清楚写明白，两边都少扯皮。

  1. 买之前让卖家拍实物视频，重点拍序列号、屏幕、接口和划痕。
  2. 只在平台内下单付款，别走微信、别点对方发的链接。
  3. 收货当面或当天验货，有问题立刻在平台内申请退款并上传证据。
  4. 卖东西时标明成色、配件、有无维修、是否包邮。
  5. 贵重物品寄出前拍打包视频，用可保价的快递。

容易踩什么坑

  • 「先款后货」「先货后款」都有风险，走平台担保交易才安全。
  • 二手手机要查序列号是否激活、是否被锁、是否还在保。
  • 面交选人多的地方，别单独去对方指定的地点。

依据

  • 《中华人民共和国消费者权益保护法》（2013年修正）
    第二十五条：经营者采用网络、电视、电话、邮购等方式销售商品，消费者有权自收到商品之日起七日内退货且无需说明理由；并列出不适用该规则的商品
  • 《网络交易监督管理办法》（市场监管总局令第37号）
    规定网络交易经营者采取自动展期、自动续费等方式提供服务的，应在接受服务前和续费日期前以显著方式提请消费者注意，并提供显著、简便的随时取消或变更选项，不得收取不合理费用
