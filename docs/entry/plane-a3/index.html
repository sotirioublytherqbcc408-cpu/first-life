第一次向 12326 投诉航班服务问题

证据 B增补花费：0耗时：30 分钟力气：中最后核对：2026-10-05

怎么办

对航班延误、行李、服务不满，除了找航司，还可以向民航服务质量监督热线 12326 投诉；投诉有期限，越早越好。

  1. 先向航司或机场书面投诉，留下工单号
  2. 未解决或不满意的，打 12326 或通过民航局投诉渠道提交
  3. 准备好票号、航班号、时间、证据（截图、录音、行李单）
  4. 注意投诉时限，别拖到几个月后再提

容易踩什么坑

  • 只口头反映不留证据，后续很难推进
  • 把天气等不可抗力当成航司责任，诉求容易落空

依据

  • 《公共航空运输旅客服务管理规定》（交通运输部令 2021 年第 3 号）
    旅客服务与投诉处理的相关规定
  • 民航局航旅指南
    民航服务监督渠道说明

为什么补这一条

投诉有时限与材料要求，先知道规则比事后着急有用
