第一次办银行卡实名和手机号实名

证据 A花费：开卡与入网一般免费耗时：各 30–60 分钟力气：低最后核对：2026-10-05

怎么办

开银行卡和办手机号都必须实名登记。个人银行账户分 I、II、III 类，功能和使用限额不同；手机号按电话用户真实身份信息登记的规定办理。这两样现在都是骗子最喜欢借用的东西。

  1. 本人带身份证到银行网点或运营商营业厅办理，配合人脸识别和身份核验。
  2. 开卡时问清是几类账户：I 类功能最全，II/III 类有额度和场景限制。
  3. 手机号入网后，可在运营商 App 查询名下号码，发现不是自己办的号码立即申诉注销。
  4. 换号、销户前先解绑银行卡、支付软件和各类账号，避免收不到验证码。

容易踩什么坑

  • 把银行卡、手机卡借给或卖给他人使用，可能构成帮助信息网络犯罪活动罪。
  • 名下有多张不用的卡和号，不注销就一直是风险敞口。
  • 随便把验证码告诉“客服”，等于把账户交出去。

依据

  • 中国人民银行有关负责人就《关于改进个人银行账户分类管理有关事项的通知》答记者问（中国政府网）
    页面含“银行账户”（34 处）、“分类”（16 处），解释 I、II、III 类个人账户的功能与限额。
  • 《电话用户真实身份信息登记规定》（工业和信息化部令第 25 号）
    页面含“真实身份”（30 处）、“电话用户”（24 处），规定入网实名登记与查验要求。
