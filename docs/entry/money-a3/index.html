第一次看懂合同里的利息和年化

证据 A增补花费：可能差出数倍利息耗时：20 分钟力气：中最后核对：2026-10-05

怎么办

「日息万分之五」「月费率 0.6%」听起来很低，换算成年化差别很大。看懂年化利率是贷款和分期最常见的认知陷阱。

  1. 把各种说法统一换算成年化利率（APR）：日息×365，月费率×12 只是粗略近似
  2. 注意「费率」和「利率」不同：等额本息还款下，费率算出来的实际年化约为标称值的 1.8 倍左右
  3. 问清提前还款是否有违约金、是否仍收剩余期数的手续费
  4. 把合同里的费用条款拍照留存

容易踩什么坑

  • 只看「每期还多少」，不算总还款额
  • 忽略服务费、担保费、会员费，这些也要计入真实成本

依据

  • 《银行保险机构消费者权益保护管理办法》
    金融机构应明示年化利率，不得仅以日利率、月费率等方式误导消费者
  • 《商业银行信用卡业务监督管理办法》
    信用卡分期业务应披露年化利率与收费方式

为什么补这一条
