第一次复印病历（病案室流程）

证据 A增补花费：按页收费耗时：1–3 天力气：中最后核对：2026-10-05

怎么办

转院、报销、保险理赔、纠纷处理都可能要病历复印件。出院后到病案室申请，本人带身份证，代办要带委托书。

  1. 出院时先问清病案室位置、复印办理时间和所需材料
  2. 本人办理：身份证；代办：患者身份证复印件 + 代办人身份证 + 委托书
  3. 明确要复印的范围：住院病案首页、入院记录、病程记录、检查报告、出院小结
  4. 核对页数与盖章，保留一份电子扫描件

容易踩什么坑

  • 出院后隔太久才去，部分医院归档需要等待
  • 只复印了出院小结，理赔时才发现材料不全

依据

  • 《医疗纠纷预防和处理条例》（国务院令第 701 号）
    患者有权查阅、复制病历资料，医疗机构应当提供

为什么补这一条

转院、报销、理赔、纠纷都要病历复印件，很多人出院后才发现
