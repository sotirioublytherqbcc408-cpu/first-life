第一次一个人吃饭、一个人看电影、一个人逛商场

证据 C花费：人均几十到一百多元耗时：2–4 小时力气：低最后核对：2026-10-05

怎么办

一个人出门最难的其实是进门那一步，坐下之后就没什么了。第一次可以先挑人少的时间段。

  1. 一个人吃饭选吧台位、快餐或小吃店，点单快、翻台快，不用占着大桌。
  2. 点菜按人头来：一个人点一个主食加一个菜就够，吃不完就打包，餐饮服务经营者本就应引导适量点餐。
  3. 看电影工作日白天场最便宜、人也最少，取票后直接在影厅门口等，不用提前很久到。
  4. 逛商场把目的想清楚：是买什么、还是只是走走，不然很容易在负一层被消费掉半天。

容易踩什么坑

  • 一个人吃饭不敢催菜、不敢换座位，其实这些都很正常。
  • 看电影前买大桶饮料，中途跑厕所错过关键情节。

依据

  • 中华人民共和国反食品浪费法（中国人大网）
    规定餐饮服务经营者应引导消费者按需适量点餐、提供打包服务，消费者应合理点餐。 已用 curl 抓取本页并核对到关键词：「反食品浪费」、「按需」、「打包」。
  • 电影票全面支持「退改签」，APP付款前需弹出退改签协议（文汇报）
    报道中国电影发行放映协会2018年发布的电影票退改签规定；协会官网只有JS页面，curl 取不到原文，故本条降为权威媒体报道（B级）。 已用 curl 抓取本页并核对到关键词：「退改签」、「电影票」。
