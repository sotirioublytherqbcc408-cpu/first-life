第一次买二手手机、电脑和车

证据 B花费：新车价的几成，车还要加过户费耗时：1 天到几周力气：高最后核对：2026-10-05

怎么办

二手大件的共同点是：看得见的问题不是问题，看不见的才是。手机看序列号和电池，电脑看硬盘使用时间和维修记录，车看登记证书和事故记录。

  1. 手机：查序列号激活状态、是否被锁、电池健康、有无拆修。
  2. 电脑：看硬盘通电时间、屏幕坏点、接口，重装系统后再验一次。
  3. 车：核验机动车登记证书、行驶证、车主身份，查违章和事故记录。
  4. 见面验货选白天、人多的地方，当面测完全部功能。
  5. 车必须去车管所办转让登记，交验机动车并提交现所有人身份证明等材料。

容易踩什么坑

  • 二手车不过户，之后的违章和事故可能还算在你头上。
  • 「一手车、无事故」的口头承诺不作数，要看维修保养和检测报告。
  • 二手电子产品多半没有发票和保修，价格要相应打折。

依据

  • 《机动车登记规定》（公安部令第164号，深圳市公安局公开页）
    申请转让登记的，现机动车所有人应当交验机动车，并提交现机动车所有人身份证明等证明、凭证
  • 《家用汽车产品修理更换退货责任规定》（市场监管总局令第43号）
    第二十条、第二十三条：家用汽车产品自三包有效期起算之日起60日内或者行驶里程3000公里之内（以先到者为准），符合条件的可更换或退货
