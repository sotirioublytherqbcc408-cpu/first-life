第一次忘带身份证：民航临时乘机证明怎么办

证据 B增补花费：0–几十元耗时：30–60 分钟力气：低最后核对：2026-10-05

怎么办

到机场才发现没带身份证，不用直接放弃航班：多数机场设有公安制证点或支持线上申领「临时乘机证明」，凭它过安检登机。

  1. 先到出发层问询处或机场公安制证点，说明航班与时间
  2. 按指引在「民航临时乘机证明」小程序做人脸核验并生成二维码
  3. 留足时间：办证加安检通常要 30–60 分钟
  4. 平时把身份证照片存在手机加密相册，只能应急佐证，不能代替证件

容易踩什么坑

  • 身份证过期同样不能用，别指望过期证件能过安检
  • 临时证明有有效期与使用范围限制，返程要另外办

依据

  • 民航局航旅指南
    民航局航旅指南对乘机证件要求的说明

为什么补这一条

大纲没写，但这是机场最高频的意外
