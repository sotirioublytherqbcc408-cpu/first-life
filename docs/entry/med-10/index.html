第一次挂急诊，第一次半夜去医院

证据 A花费：急诊挂号与检查费用耗时：数小时力气：高最后核对：2026-10-05

怎么办

急诊是按病情轻重排序，不是按先来后到：分诊护士会先测生命体征、分级，危重病人优先。半夜去急诊流程和白天差不多，但只有急诊科、检验和影像的值班力量。

  1. 到急诊先找分诊台，说清最要紧的症状和开始时间，配合测量体温、血压、血氧。
  2. 带身份证、医保凭证和以往病历；如果有在吃的药，带上药盒或拍照。
  3. 按分级等待叫号，期间如果症状明显加重，立刻再找分诊护士，不要硬等。
  4. 离开前问清：回家后什么情况要立刻再来、复诊挂哪个科、药怎么吃。

容易踩什么坑

  • 因为等待时间长就和护士争吵，反而耽误自己的分诊评估。
  • 半夜独自去急诊又没人陪同，需要做检查或缴费时手忙脚乱。
  • 症状缓解就自行离院，没有办离院手续，病历和费用都不完整。

依据

  • 院前医疗急救管理办法（国务院公报）
    页面含“急救”（116 处）、“院前”（56 处），规定院前急救与院内急诊衔接的要求。
  • 医疗机构管理条例（安徽省卫生健康委员会）
    页面含“医疗机构”“诊疗”，用于核对医疗机构急诊救治的执业要求。
