第一次处理家庭财产：遗产、遗嘱与公证

证据 A花费：公证费按标的比例，因人而异耗时：1–6 个月力气：中最后核对：2026-10-05

怎么办

家里有人去世后要处理的第一件事不是分东西，而是弄清楚有没有遗嘱。有遗嘱按遗嘱办，没有遗嘱按法定继承顺序办。

  1. 先找出所有可能的遗嘱（自书、代书、打印、录音录像、公证），以及房产证、存单、股权凭证、保险合同。
  2. 没有争议的，去公证处办继承公证：所有继承人带身份证、户口本、死亡证明、亲属关系证明和财产凭证到场。
  3. 谈不拢的走法院诉讼，别在家里耗着，时间越久证据越难找。
  4. 涉及老人的财产安排，趁父母意识清醒时办遗嘱公证，公证文书的证据效力最稳。

容易踩什么坑

  • 以为独生子女就能直接继承：配偶、子女、父母同属第一顺序继承人，祖父母外祖父母也可能牵涉其中。
  • 只在微信里达成一致、没有书面签字，后面翻脸的很多。
