第一次牵手、拥抱与确定关系

证据 A花费：无耗时：因人而异力气：中最后核对：2026-10-05

怎么办

身体接触的前提是对方愿意，任何时候都可以说不，也都可以收回。确定关系则最好说清：我们是什么关系、要不要公开、是否只和彼此交往。

  1. 从小的接触开始，观察对方的反应，犹豫就停下来问一句
  2. 任何一步都可以问：「我可以牵你的手吗」，直接问并不扫兴
  3. 确定关系时把关键的事说清楚：是否专一、是否公开、怎么称呼
  4. 把自己不能接受的事提前说（比如查手机、突然失联）
  5. 关系变了、想法变了，及时说，不要靠冷淡逼对方提分手

容易踩什么坑

  • 「都在一起了」不能构成任何身体接触的许可，违背意愿的言语、肢体行为可能构成性骚扰
  • 不明说的暧昧会持续消耗双方，该界定就界定
  • 被拒绝亲密接触不等于不喜欢你，节奏不同很正常

依据

  • 《中华人民共和国民法典》人格权编
    第九百九十条：人格权包括生命权、身体权、健康权等；第一千零一十条：违背他人意愿，以言语、文字、图像、肢体行为等方式对他人实施性骚扰的，受害人有权依法请求行为人承担民事责任

它覆盖了哪些「第一次」

  • 第一次牵手
  • 第一次拥抱
  • 第一次正式确定关系
