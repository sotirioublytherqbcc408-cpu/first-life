第一次打针、打点滴和缝针

证据 A花费：几十元到几百元耗时：30 分钟到数小时力气：中最后核对：2026-10-05

怎么办

打针、输液、缝针都属于有创操作，在门诊治疗室或急诊清创室完成。输液前护士会核对姓名、药名和过敏史，这一步一定要配合确认，不要嫌麻烦。

  1. 输液先去缴费、取药，再到输液室交药和输液单，取号等叫号。
  2. 护士核对姓名和药名时认真应答，主动说出药物过敏史。
  3. 输液过程中不要自己调滴速；出现发冷、皮疹、心慌，立刻按呼叫铃。
  4. 缝针后问清换药时间、拆线时间和伤口护理要求，按时间去复诊。

容易踩什么坑

  • 为了赶时间自己调快滴速，可能引起不良反应。
  • 针眼按压时间不够，淤青或者出血。
  • 缝针后不按时换药、不拆线，伤口感染或留疤。

依据

  • 医疗机构管理条例（安徽省卫生健康委员会）
    页面含“医疗机构”“诊疗”“执业”，规定诊疗活动与护理工作的基本规范。
  • 医疗纠纷预防和处理条例（中国政府网）
    页面含“病历”，用于核对诊疗记录与知情告知要求。

它覆盖了哪些「第一次」

  • 第一次打针
  • 第一次打点滴
  • 第一次缝针
