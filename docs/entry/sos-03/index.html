第一次护照在境外丢失

证据 C花费：补办费耗时：1–数天力气：高最后核对：2026-10-05

怎么办

在境外丢护照，顺序是：报警拿证明 → 联系中国使领馆补办旅行证 → 再改签行程。别抱侥幸直接去机场。

  1. 到当地警察局报案，索取报警证明（多数国家补证必需）
  2. 联系中国驻当地使领馆，申请补发护照或旅行证
  3. 复印/拍照留存原护照与签证页，必要时联系移民局补入境记录

容易踩什么坑

  • 没有报警证明，很多使领馆不受理补证
  • 先确认签证是否需要重新办理再订机票

依据

  • 中国政府网（政策与办事服务入口）
    中国公民在境外证件遗失，由中国驻外使领馆受理补发
