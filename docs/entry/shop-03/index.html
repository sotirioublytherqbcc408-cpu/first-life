第一次寄快递和收快递

证据 A花费：按重量和距离计费，保价另收耗时：寄件 15 分钟，市内次日到力气：低最后核对：2026-10-05

怎么办

寄快递要实名并配合验视，这是条例要求，不是快递员为难你。贵重物品要保价，否则丢失时按快递服务合同约定赔偿，可能远低于物品实际价值。

  1. 手机下单或去网点，填清寄件人和收件人的电话、地址。
  2. 交寄时出示身份信息，配合开箱验视。
  3. 贵重、易碎物品主动保价，并在运单上写明内件名称。
  4. 寄出后保留运单号和寄件凭证，拍下打包过程。
  5. 收件先验外包装，破损当场拒收或拍照，再拆箱验内件。

容易踩什么坑

  • 不保价的快件丢失，赔偿通常按运单约定而不是物品实际价值。
  • 违禁品、易燃易爆品、现金和重要证件不要寄，会被扣件甚至担责。
  • 快递放驿站或柜子导致丢件可以投诉，但先确认自己有没有勾选同意代收。

依据

  • 《快递暂行条例》（国务院令第697号）
    规定寄件人应提供身份信息并配合验视；企业应告知保价规则；用户合法权益因快件延误、丢失、损毁或内件短少受损害的，可要求运单所属企业赔偿
  • 国家邮政局系统·快递业务旺季服务消费提示（云南省邮政管理局）
    官方提示用户保留运单、及时验视、通过正规申诉渠道维权
