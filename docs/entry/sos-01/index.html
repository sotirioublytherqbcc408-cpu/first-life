第一次手机丢失

证据 C花费：0–数千元耗时：1–3 小时力气：中最后核对：2026-10-05

怎么办

手机丢了，第一件事不是找手机，而是切断它能造成的损失：先挂失 SIM 卡、冻结支付、再远程锁定与抹除。

  1. 借别人的手机打运营商客服挂失 SIM（移动 10086 / 联通 10010 / 电信 10000）
  2. 用另一台设备登录云账号，开「查找设备」→ 远程锁定或抹除
  3. 打支付宝 95188、微信支付客服冻结账户
  4. 报警并留好报案回执，方便后续申诉

容易踩什么坑

  • 先挂 SIM 再谈找回，否则验证码会被用来登录你的账号
  • 别在陌生设备上登录网银

依据

  • 中国政府网（政策与办事服务入口）
    运营商与支付机构的挂失、冻结流程以各自官方客服为准
