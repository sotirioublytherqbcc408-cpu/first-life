第一次开无犯罪记录证明

证据 A花费：免费耗时：线上 1–3 个工作日，线下当场或次日力气：低最后核对：2026-10-05

怎么办

无犯罪记录证明由公安机关出具，用于特定的入职、入学、出国等场景。近几年多地已支持线上申请和跨省通办，同时也在推行以专项信用报告替代“无违法违规记录证明”。

  1. 先问受理单位要什么：纸质的还是电子的、有没有有效期要求、抬头怎么写。
  2. 通过当地公安 App、政务服务网或公安窗口提交申请，带身份证，说明用途。
  3. 按提示领取电子证明或到窗口领取纸质证明。
  4. 如果属于“有无违法违规记录”类用途，问清能否用专项信用报告替代，少跑一趟。

容易踩什么坑

  • 用途写得太笼统被退回，重办要重新等。
  • 证明有有效期（多为 1–3 个月，以出具单位标注为准），开太早作废。
  • 伪造、变造证明属于违法行为。

依据

  • 公安部答网民关于“自助机上没法办理无犯罪记录证明”问题的留言（中国政府网）
    页面含“无犯罪记录证明”（9 处）、“派出所”，是公安部对办理渠道的官方答复。
  • 国家发展改革委 公安部 国家数据局关于全面推行以专项信用报告替代有无违法违规记录证明的通知（中国政府网）
    页面含“信用报告”（56 处）、“证明”（24 处），说明哪些场景可以用专项信用报告替代证明。
