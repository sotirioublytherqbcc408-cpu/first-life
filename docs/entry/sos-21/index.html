第一次意识到紧急联系人与「提前知道怎么办」有多重要

证据 C花费：0耗时：30 分钟力气：低最后核对：2026-10-05

怎么办

紧急联系人不是填个名字就完事：要写在手机锁屏可见处、告诉家人你的过敏史与常用药，并把关键号码背下来两个。

  1. 在手机锁屏页或医疗急救卡里写明紧急联系人与过敏史
  2. 家人之间互相存好常用医院、社区电话、物业电话
  3. 把 120/110/119 之外的两个关键号码背下来（如家人、社区医生）
  4. 每半年更新一次信息

容易踩什么坑

  • 手机没电或丢失时，纸质卡片反而最可靠
  • 别把紧急联系人只存在聊天记录里

依据

  • 中国红十字会总会（救护培训与急救知识）
