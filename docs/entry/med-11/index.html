第一次住院：办住院手续、手术到出院（含陪护）

证据 A花费：押金+自付部分，视病情耗时：数天到数周力气：高最后核对：2026-10-05

怎么办

住院是一条固定流程：门诊开住院单→住院处办手续交押金→进病区→检查和治疗→出院结算。手术前必须由医生说明情况并签署同意书，这是法定的知情同意程序。

  1. 拿住院单到住院处办手续：带身份证、医保凭证，交押金，办好后到病区护士站报到。
  2. 住院期间留好每日费用清单，问清哪些是医保内、哪些自费。
  3. 手术或特殊检查前，医生会说明风险并让你签同意书；听不懂就问，签字前你有权了解。
  4. 出院时先到护士站办出院、拿出院小结和病历复印件，再去结算窗口办医保结算，最后按医嘱复诊。

容易踩什么坑

  • 医保卡没带或没办异地备案，出院结算时只能先自费再回参保地报销。
  • 出院小结和费用清单不拿，后面报销、复查、请假证明都缺材料。
  • 陪护时不清楚病区的探视和陪护规定，被反复劝离。

依据

  • 医疗机构管理条例（安徽省卫生健康委员会）
    页面含“医疗机构”“执业”“诊疗”，规定医疗机构住院、诊疗活动的基本要求。
  • 医疗纠纷预防和处理条例（中国政府网）
    页面含“病历”“调解”“知情”，规定手术等需说明并取得书面同意、病历资料查阅复制。

  • 第一次手术
