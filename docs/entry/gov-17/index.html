第一次起诉、收到法院传票、当原告或被告、第一次出庭

证据 A花费：诉讼费按标的额，败诉方通常承担耗时：立案数日，审结数月力气：高最后核对：2026-10-05

怎么办

打官司的流程是：写起诉状→向有管辖权的法院立案→送达→开庭→判决。收到传票不要躲，按时出庭是你的程序权利；不出庭可能被缺席判决。

  1. 原告：写起诉状（当事人信息、诉讼请求、事实与理由），带证据材料到法院立案窗口或线上立案。
  2. 被告：收到起诉状副本和传票后，在答辩期内提交答辩状，准备证据。
  3. 开庭前整理证据清单，准备好原件，按通知的时间到庭、带身份证。
  4. 庭审后按判决履行或在上诉期内决定是否上诉；材料全程留存。

容易踩什么坑

  • 收到传票不理不睬，法院可以缺席判决，结果对你不利。
  • 证据只在开庭时口头说，没有提交书面材料。
  • 错过上诉期，判决生效后再想改就难了。

依据

  • 中华人民共和国民事诉讼法（最高人民法院公报）
    页面含“起诉”（18 处）、“传票”（2 处）、“证据”（31 处），规定起诉、受理、送达、开庭与判决程序。
