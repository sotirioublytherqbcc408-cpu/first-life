第一次报警与去派出所

证据 C花费：0耗时：1–3 小时力气：中最后核对：2026-10-05

怎么办

报警说清三件事：在哪、发生了什么、有没有人受伤。到派出所做笔录前，先把时间线和证据在手机备忘里列好。

  1. 拨 110，说清地点、事由、人数与伤情
  2. 保存现场照片、聊天记录、转账凭证
  3. 到派出所如实陈述，笔录可以要求核对后签字
  4. 索取报案回执或受案登记表，后续要用

容易踩什么坑

  • 报案不等于立案，拿回执才能证明你报过案
  • 别自行删改聊天记录，证据链会断

依据

  • 中国政府网（政策与办事服务入口）
    公安机关受案、立案与报案回执相关规定
