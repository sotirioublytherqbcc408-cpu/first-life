第一次准备家庭应急包

证据 C增补花费：200–500 元耗时：半天力气：中最后核对：2026-10-05

怎么办

应急包的目标是：家里断水断电、或需要立刻撤离时，能撑过 72 小时。

  1. 按人头备 3 天饮用水与免煮食物
  2. 手电、备用电池、口哨、多功能刀、充电宝
  3. 常用药与急救包（纱布、创可贴、碘伏）
  4. 证件复印件、少量现金、备用钥匙

容易踩什么坑

  • 要放在拿得到的地方，别塞进储藏室最深处
  • 每半年检查一次有效期与电池

依据

  • 中国红十字会总会（救护培训与急救知识）
    家庭应急物资与救护常识
  • 中国地震局
    地震应急准备建议

为什么补这一条

水、手电、口哨、常用药、证件复印件，地震火灾都用得上
