第一次坐船、第一次坐游轮、第一次潜水

证据 A花费：因人而异耗时：半天到数天力气：中最后核对：2026-10-05

怎么办

水上项目看着温柔，真出事时留给你的反应时间很短，所以规则都在上船前讲完。

  1. 上船先找救生衣和逃生路线，全程按要求穿好救生衣。
  2. 坐游轮多是出境行程，提前办好护照签证；船上是记账消费，离船前统一结算，看清账单再下船。
  3. 潜水必须找有资质的经营者（潜水属于高危险性体育项目，须取得许可），下水前如实告知病史，全程不单独行动。
  4. 浮潜要有教练带着，别脱离队伍去追鱼。

容易踩什么坑

  • 潜水后短时间内坐飞机是常见禁忌，行程别排太紧。
  • 晕船最有效的是提前吃药，上船后再吃往往来不及。

依据

  • 第一批高危险性体育项目目录公告（国家体育总局公告第16号，中国政府网）
    公告第一批高危险性体育项目为游泳，高山滑雪、自由式滑雪、单板滑雪，潜水，攀岩；经营这些项目须依《全民健身条例》取得许可。
  • 《中国领事保护与协助指南》和《中华人民共和国领事保护与协助条例》（中国驻外使馆网站）
