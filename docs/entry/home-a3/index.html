第一次给家里做应急信息卡（病历、用药、紧急联系人）

证据 C增补花费：0耗时：30 分钟力气：低最后核对：2026-10-05

怎么办

父母突发疾病时，抢救室里最需要的是既往病史、过敏史和常用药清单。提前写下来放在钱包里，比事后翻手机快得多。

  1. 列出父母的基础病、手术史、过敏史、常用药与剂量
  2. 写上主治医院、科室、医生电话与医保类型
  3. 填两个紧急联系人，注明关系与电话
  4. 打印两份：一份放老人钱包，一份拍照存家庭群

容易踩什么坑

  • 信息过期比没有更危险，每半年更新一次
  • 只存在手机里，老人外出手机没电就查不到

依据

  • 中国红十字会总会（救护与家庭应急准备）
