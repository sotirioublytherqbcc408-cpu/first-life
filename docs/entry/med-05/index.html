第一次做胃镜（含无痛胃镜）

证据 A花费：普通胃镜几百元，无痛更贵耗时：半天（含等待与苏醒）力气：高最后核对：2026-10-05

怎么办

胃镜是医生把内镜从口腔送进食道、胃和十二指肠看一遍，必要时取一小块组织做病理。做不做无痛（麻醉）由医生评估，麻醉需要家属陪同，当天不能自己开车。

  1. 按医嘱做术前准备：通常需要禁食禁水若干小时，具体时间以医院告知为准。
  2. 如实告知病史和用药（尤其是抗凝、抗血小板类药物）、过敏史，由医生判断是否需要调整。
  3. 检查时按医生指令吞咽、呼吸；无痛胃镜会在麻醉下完成，醒来可能有喉咙不适。
  4. 取活检的，按告知的时间取病理报告，再带着报告复诊。

容易踩什么坑

  • 没按要求禁食，只能改期重约。
  • 做无痛胃镜没人陪同，医院可能不给做。
  • 做完就开车或骑车走，麻醉残留有风险。

依据

  • 医疗机构管理条例（安徽省卫生健康委员会）
    页面含“诊疗”“执业”，用于核对医疗机构开展内镜等诊疗活动的执业要求。
  • 医疗纠纷预防和处理条例（中国政府网）
    页面含“病历”“知情”，规定实施手术、特殊检查等应当向患者说明并取得同意。
