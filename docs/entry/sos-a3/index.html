第一次在手机上开启地震预警

证据 B增补花费：0耗时：2 分钟力气：低最后核对：2026-10-05

怎么办

多数国产手机系统内置地震预警（在设置里搜「地震预警」），能提前几秒到几十秒报警，够你躲到桌子下。

  1. 在手机设置里搜索「地震预警」并开启
  2. 确认定位与通知权限都打开
  3. 把预警音量调到最大，熟悉警报声
  4. 提醒家人也各开一遍

容易踩什么坑

  • 关掉通知权限等于没开
  • 预警时间随距离变化，只有几秒也要按伏地、遮挡、抓牢来做

依据

  • 中国地震局
    中国地震局：地震预警与避险科普

为什么补这一条

手机里就有这个功能，几十秒预警足够躲到桌下
