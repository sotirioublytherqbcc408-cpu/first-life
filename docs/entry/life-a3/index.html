第一次和室友分摊水电网费

证据 C增补花费：每月几十到几百元耗时：10 分钟力气：中最后核对：2026-10-05

怎么办

合租最容易起矛盾的就是钱：水电网燃气怎么分。趁关系好时先定规则，比事后算账容易得多。

  1. 入住前约定分摊方式：按人头平摊，还是按房间面积/使用量
  2. 约定由谁代缴、每月几号结算、用哪个工具记账
  3. 把规则写在合租协议或群里，保留转账记录
  4. 耗电差异大的设备（取暖器、矿机）单独约定

容易踩什么坑

  • 只口头说「到时候再说」，第一个月账单出来就尴尬
  • 代缴的人垫付后不收据，时间一长算不清

依据

  • 《中华人民共和国消费者权益保护法》
    民事活动应遵循公平与诚实信用原则，合租费用分摊以各方约定为准

为什么补这一条
