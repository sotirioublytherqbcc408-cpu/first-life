第一次使用 GitHub、第一次提交代码、第一次发布自己的项目

证据 B花费：0 元（公开仓库）耗时：1–3 天力气：中最后核对：2026-10-05

怎么办

GitHub 是把代码放到网上、并且记录每一次改动的地方。对新手来说，先跑通创建仓库、提交、发布这三个动作就够了。

  1. 注册账号后建一个仓库，勾选 README，先让仓库有内容。
  2. 在网页上直接改文件并提交，感受一次完整的提交记录，再学本地 Git。
  3. 给项目写一个说得清的 README：这是做什么的、怎么跑起来、依赖什么。
  4. 发布时打上版本标签并写 Release 说明；涉及密钥、手机号、身份证的文件绝不能提交上去。

容易踩什么坑

  • 把 API Key 和密码提交到公开仓库，机器人几分钟内就会扫到并盗用。
  • 提交历史里删掉文件不等于消失，敏感信息一旦推上去要立刻更换密钥。
