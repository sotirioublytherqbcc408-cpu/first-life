第一次拨打 120 / 110 / 119

证据 C花费：0耗时：几分钟力气：低最后核对：2026-10-05

怎么办

三个号码分工不同：120 医疗急救、110 治安与刑事、119 火灾与救援（现在也承担综合救援）。拨打时说清地址、人数、伤情，并保持电话畅通。

  1. 确认地址：小区名 + 楼栋 + 单元 + 门牌，或最近的路口/店铺名
  2. 说清人数、伤情/火情、是否需要破拆救援
  3. 派人到路口接应，保持电话不占线
  4. 按接线员指示做，不要先挂电话

容易踩什么坑

  • 地址说不清是延误救援的最大原因
  • 不要为了「快点来」夸大伤情，会占用资源

依据

  • 中国政府网（政策与办事服务入口）
    120/110/119 职责分工与报警要求，以各地主管部门公告为准
  • 《中华人民共和国消防法》（2021 修正全文，北京市人民政府门户网站转载）
    各单位与个人有维护消防安全、保护消防设施、报告火警的义务；任何人发现火灾都应当立即报警（已 curl 核验页面含「消防法」「火灾」65 处、「灭火」15 处、「疏散」12 处）（原 119.gov.cn 对脚本请求返回 412，改用可核验的法律全文）
